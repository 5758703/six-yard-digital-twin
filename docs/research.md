# 资料检索与空间依据

日期：2026-09-20。

## 地理核查

通过 Overpass 对涿州地区“亨通、火炬、朝阳、范阳”命名道路进行查询，原始发现结果保存在 `public/data/osm-road-discovery.json`。确认道路：

- 朝阳路：OSM way 208485882。
- 亨通大街：208485885、471022751。
- 火炬街：208485897。
- 范阳中路：156261177、471022676 等分段。

随后按来源记录中的包围盒取得 83 个要素。住宅使用 OSM polygon，楼高没有相应数据，统一以近似层高建模。装备专业化大楼合并 390196010 与 390196198 所在区域；北侧截图建筑取代 390195851 对应的配套轮廓，避免重复覆盖。

截图并无坐标系和测绘控制点。办公楼坐标是与外围路网及周围 OSM 建筑相对对齐的近似位置，不能当作地籍或测量坐标。
