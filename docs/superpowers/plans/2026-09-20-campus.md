> Execute inline using executing-plans. User supplied the missing building locations; continue the authorized project without another approval gate.

**Goal:** Deliver an interactive Vue campus twin and reproducible Blender assets.
**Architecture:** Shared local-meter campus JSON feeds Blender geometry and Three.js interaction. Deterministic simulation feeds both positions and dashboard counts; OSM raw data and provenance remain separate from screenshot-derived geometry.
**Tech Stack:** Vue 3, TypeScript, Vite, Three.js, Blender Python, Node test runner.
**Spec:** ../../design-proposal.md

## Constraints and decisions

- Do not claim surveyed geometry or photographed elevations. Downloaded data timestamp must be actual.
- Work in the empty current project; no publication requested. Use local preview and deliver source.
- Colors: slate #101c26, panel #172833, text #e5edf0, teal #64d7c0, amber #edb867. Scene itself is daylight natural materials, not a glowing wireframe.

## Tasks
- [x] Data: scripts/fetch-osm.mjs saves raw Overpass response and provenance; public/data/campus.json stores annotated layout. Check named boundary road coordinates and evidence limitations.

- [x] Viewer: src/scene.ts loads GLB, orbit camera, picking, focus, labels, day/night, independent layers and animated actors. src/App.vue implements search, metrics, alerts, provenance and replay. src/style.css implements responsive workspace.
- [x] Validation: npm run build, npm test, browser check real canvas and every major interaction. README includes commands, data lineage, asset generation and limitations. Save validation findings and screenshot.
