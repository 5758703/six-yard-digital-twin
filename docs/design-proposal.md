# 涿州平安小区六号院数字孪生项目方案

状态：已实现并验证，用户补充标注已用于定位国际部大楼与装备专业化大楼。日期：2026-09-20。最终交付与限制见 README.md 和 validation.md。

## 交付目标

完整 Vue 3 + TypeScript + Vite + Three.js 项目，附 Blender 场景生成脚本、可编辑 .blend、导出的 GLB 模型、展示渲染图、数据来源记录、安装运行说明和验证记录。交付可本地运行的项目；在线发布单独处理。

## 范围与真实性

用户截图为范围参考，不作为额外指令。可辨识北侧朝阳路、南侧范阳中路、西侧亨通大街、东侧火炬街。最终地理边界须与实际 OSM 路网核对；截图来源和坐标系统未知，不直接将像素位置视为 WGS84。

国际部大楼、装备专业化大楼的名称来自用户；具体建筑对应位置尚未核实。允许配置坐标和更换模型，缺证据时必须标识“位置/外观待核实”，不宣称精确复原。

OSM 数据尚未下载。实现时保存实际请求范围、原始响应、下载 UTC 时间、OSM 数据时间和 SHA-256；下载日期与数据编辑日期分别记录。只有真实下载成功且范围核对通过后，才标注“2026-09-20 下载的 OSM 数据”。OSM 缺失的内部道路、楼体和树木以截图辅助近似建模并记录来源，不伪装成 OSM 要素。

## 方案选择

推荐混合方案：OSM 提供有据可查的空间骨架，Blender 制作建筑、梧桐树、车辆和行人资产，Three.js 实时渲染与交互。离线 Cycles 渲染用于展示图；网页使用 GLB、PBR 材质、阴影和环境光。

纯程序化 Three.js 方案实现较快，但不满足完整 Blender 资产交付。纯 Blender 动画渲染可提高静帧质量，但不能独立实现网页上的自由观察和交互，因此均不采用。

## 页面与功能

- 全屏三维工作区，深色简洁控制面板。默认日间写实视角，支持俯视、轨道观察、复位和昼夜切换。
- 建筑搜索支持名称和编号，结果可点击飞行定位、轮廓高亮并查看用途、楼层、来源可信度和模拟指标。
- 展示重点办公楼、住宅楼、内部与外围道路、路侧梧桐树、停车位、路灯、标线和入口；无法考证的尺寸及树种位置标为近似。
- 行人沿步行路线行走，车辆沿车道行驶；车辆支持驶入车位、停放和离场，显示可选轨迹。
- 模拟人员数、车辆数、停车占用率和运行指标统一由模拟状态派生，明确标识模拟数据。
- 模拟告警可触发、定位、确认和解除，保存事件时间；点击事件进入回放。
- 回放支持播放、暂停、倍速和时间轴拖动。共享模拟时钟和固定随机种子，同一时间点得到一致的位置、车位状态和告警状态。
- 图层控制覆盖建筑标签、树木、行人、车辆和轨迹。加载失败或 WebGL 不可用时显示具体错误与重试入口。

## 模块与数据

Vue 管理面板和应用状态，Three.js 场景模块负责渲染、拾取、定位和资源销毁，独立模拟模块按时间计算运动与事件。建筑数据保留稳定 ID、经纬度/局部坐标、来源、可信度和模型路径。Blender 脚本读取同一份场地配置，避免导出模型与交互定位错位。

资源使用分级细节、重复物体实例化及受控阴影范围；按设备像素比和渲染质量设置平衡性能。用户上传截图仅作参考，第三方照片保留来源，不把未获再分发许可的照片直接作为交付贴图。

验收包括生产构建成功、真实浏览器加载与截图、建筑搜索定位、图层切换、车辆停车与行人动画、告警处理和时间轴回放。模拟核心检查暂停后状态不变、同时间回放可重复、停车占用不超过容量；模型确认 GLB 实际加载、.blend 可打开和渲染输出存在。
